# Yiji Personal Finance

Personal finance app using enablebanking.com to aggregate transaction data to manage spending.

## Categories

Category of spending is assigned by AI model (currently using cloud models from ollama) or by hand.

## Filters

Charts can be filtered by Category, or Counterparty (transfer recipient).
Last week or last month periods can be compared with same periods from last month or year.
