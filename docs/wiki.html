Yiji

One-page personal finance app: bank transactions from Enable Banking, shown as filterable graphs. Scaffold stage: Enable Banking integration not yet built.

  ui/

  unit/              pytest
  e2e/               Playwright; conftest starts uvicorn; pages/ = page objects

Usage

uv sync                                   # install
uv run playwright install chromium        # once, for E2E
uv run python -m app                      # run → http://127.0.0.1:8100
uv run ruff check . && uv run ruff format --check .
uv run pyright
uv run pytest                             # unit
uv run pytest -m e2e                      # E2E

Config

Env vars or .env at the project root (see .env.example); the file is found from any working directory. Empty values count as unset.

VariableDefaultPurpose
YIJI_APP_TITLEYijiHeader and browser title
YIJI_STORAGE_SECRETchange-meNiceGUI session storage signing secret
YIJI_HOST127.0.0.1Bind address
YIJI_PORT8100HTTP port (1–65535)
YIJI_RELOADfalseAuto-reload on code changes (dev)
ENABLE_BANKING_APP_ID—Enable Banking application ID (production)
ENABLE_BANKING_KEY_PATH—Private key file; relative paths resolve from the project root; must exist
ENABLE_BANKING_SANDBOX_ID—Enable Banking application ID (sandbox)
ENABLE_BANKING_SANDBOX_KEY_PATH—Sandbox private key file; same path rules

Keep keys in pkeys/ (git-ignored).
